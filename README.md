# Python Mini Projects Suite

A collection of interactive Command-Line Interface (CLI) applications built using Python for my internship.

## Projects Included

### 1. To-Do List Application (`todo.py`)
- Dynamic menu interface with task status tracking (`Pending` vs `Done`).
- Add, complete, and delete tasks with full error validation.

### 2. Persistent Contact Book (`contactbook.py`)
- Persistent storage using JSON.
- Prevents duplicate entries and allows real-time search & deletion.

### 3. Robust Password Generator (`pass.py`)
- Configurable password length and character pool selection.
- Randomized shuffling for maximum security entropy.
